# Windows 安装与使用

工作台只读取 X 数据，不发帖、不修改设置，也不代填账号或密码。日常使用不需要安装 Python。请准备 64 位 Windows 10 / 11、Microsoft Edge 或 Google Chrome，以及可正常访问 X 的网络。

## 1. 下载与安装

1. 打开 [Releases 最新版](https://github.com/0xfaheng/x-analysis-workbench/releases/latest)。公开仓库无需访问授权。
2. 进入 **Releases（发布）**，在最新版本的 Assets（附件）中下载 `XWorkbench-Setup-版本号.exe`。不要下载 Source code 源码压缩包。
3. 双击安装包，按提示安装。默认只安装给当前 Windows 用户，不需要管理员权限。
4. 安装包尚未做代码签名，SmartScreen 可能提示“已保护你的电脑”。确认下载自指定仓库后，点击 **更多信息 → 仍要运行**。如果公司策略禁止继续，请联系管理员。
5. 安装结束可直接启动，也可从开始菜单打开“X 分析工作台”；安装时可勾选创建桌面快捷方式。

应用标题包含版本号。界面使用 Edge WebView2 渲染；一般已随 Windows / Edge 安装。如果启动提示缺少 WebView2 Runtime，请安装微软的 Evergreen WebView2 Runtime 后重试。

## 2. 第一次使用

首次启动先在设置卡片填自己的 X 用户名（可带或不带 `@`，限 1–15 位字母、数字或下划线），点击「保存用户名」。设置写入 `config.local.json`，保留其他键。

点击 **登录 X**，在弹出的工作台专用浏览器窗口中，手动登录界面显示的 `@handle`。验证码、双重验证等均由本人完成。检测到正确账号后窗口自动关闭，登录态保存在工作台数据目录内；最长等待 15 分钟。登录其他账号不会被当作成功。

然后点击 **更新数据与建议**（旧版名为「仅更新数据」）。工作台读取资格页和 Analytics 导出，在本机生成统计与下周建议。任务期间操作按钮禁用，可展开“运行日志”查看进度。专用浏览器与平时使用的 Edge 配置分开，通常无需关闭日常 Edge 窗口。

以后用「更多 → 修改 X 用户名」更改账号并重新登录。Windows 默认依次尝试 Edge → Chrome，无需额外下载 Playwright 浏览器；显式指定 channel 时保持该选择。需要改本机采集设置时，在 `config.local.json` 中只覆盖需要的字段。已有历史数据保留；需要隔离不同账号时使用不同的 `XWB_ROOT`。

## 3. 日常查看与更新

- 双击应用，左侧选择日期，右侧显示该期报告；左侧含门槛进度、目标达成数和“待写建议”提示。
- 点击 **更新数据与建议** 采集并生成当天报告与下周建议。同一天重复运行会刷新未编辑的程序建议，保留人工修改。
- 界面每 20 秒检查新报告，自动刷新时保留当前选择；手动更新任务成功后显示最新一期。
- 报告中的帖子与外部链接交给系统默认浏览器打开，工作台仍停留在报告页面。
- “更多”可以打开工作台文件夹、原始数据文件夹、本期 `report.md`、策略基线、周报流程及配置。

从2.2.0起，Windows/Mac 都由程序默认生成下周建议，无需 AI 或 API Key。官方规则附来源与核验日期；发帖数量、语言、题材等运营目标不是 X 的统一要求。详见 [程序建议与官方规则](程序建议与官方规则.md)。

也可以通过“更多 → 打开本期 report.md”，把报告交给任意 AI 助手，按 [周报流程](周报流程.md) 第 3 步撰写建议，再把内容填回 `<!-- SUGGESTIONS:START -->` 与 `<!-- SUGGESTIONS:END -->` 之间。保留这两个标记，保存文件后，选中该期并点击 **重新生成网页**。此按钮使用该期已有原始数据运行 `--skip-collect --date <日期>`，不打开浏览器；缺少该期原始数据时会提示失败。

## 4. 数据位置与备份

安装版默认放在 Windows 用户主目录下的 **Documents\X分析工作台**，例如 `C:\Users\用户名\Documents\X分析工作台`。可用“更多 → 打开工作台文件夹”找到实际位置。其中：

| 内容 | 位置 |
|---|---|
| 配置、目标和分类规则 | `config.json`，可选 `config.local.json` |
| 原始采集数据 | `data\raw\日期\` |
| 历次报告及手写建议 | `reports\日期\` |
| 独立浏览器登录态 | `browser-profile\` |
| 策略与流程说明 | `docs\` |

备份前等待任务结束、关闭工作台的专用浏览器窗口，再复制整个工作台数据文件夹到备份盘。浏览器登录态属于私人数据，请妥善保存；换电脑后可能仍需重新登录。不要把该文件夹或真实采集数据提交到 GitHub。

高级用户可以通过环境变量 `XWB_ROOT` 指定其他数据目录，优先级最高。便携版下载 `XWorkbench-版本号-portable.zip`，解压整个文件夹后双击 `XWorkbench.exe`；同目录有 `config.json` 时，数据直接放在该文件夹内。不要只拷贝 exe，也不要在 ZIP 内直接运行。

## 5. 升级与卸载

安装版升级：从 Releases 下载新版安装包，直接覆盖安装即可。固定的应用标识会沿用安装位置；用户数据保留，已有配置与文档不会被新版本覆盖。建议先备份数据。

便携版升级：解压新版到新的文件夹，在关闭旧版及专用浏览器后，将旧文件夹中的 `config.json`、`config.local.json`（如有）、`data`、`reports`、`browser-profile` 和自己修改过的 `docs` 复制到新版目录，覆盖新版默认配置；确认正常后再处理旧版。不要直接用压缩包中的默认 config 覆盖自己的配置。

卸载：在 Windows“设置 → 应用”中卸载“X 分析工作台”。卸载程序只移除安装文件与快捷方式，不删除 Documents 下的用户数据。如需删除数据，请先自行备份再手动处理。便携版不注册卸载项；删除其文件夹前必须备份其中的数据。

## 6. 常见问题

展开“运行日志”，按退出码处理：

| 退出码 | 含义及处理 |
|---|---|
| 0 | 成功；登录模式表示已识别目标账号。数据更新成功仍可能显示“待写建议”，按上文补写。 |
| 2 | 参数或配置错误。检查 config 的 JSON 标点、handle 和 collector 配置；必要时对照源码中的默认配置。 |
| 3 | 未登录正确账号、窗口提前关闭或登录等待超过 15 分钟。再次点“登录 X”，完成验证后重试。 |
| 4 | 采集、页面、文件或分析失败。先检查网络、X 与 Edge 状态；关闭占用导出 CSV 的 Excel 后重试。查看本期 `data\raw\日期\meta.json` 的 step/error 定位失败步骤。 |
| 5 | 缺少 markdown。安装包用户请重新下载安装最新版；源码用户安装 requirements.txt 中的依赖。 |
| 6 | 缺少 Playwright 或指定浏览器。请安装 Microsoft Edge 或 Google Chrome；安装包用户仍失败时重新安装最新版。默认 auto 按 Edge → Chrome 尝试，无需额外下载 Playwright 浏览器。 |
| 7 | 已有采集、分析或登录任务在运行。等待其结束；避免同时打开多个工作台执行任务。进程退出后可回收遗留锁，无需手动删除文件。 |

**提示 Edge 配置目录被占用**：关闭之前由工作台弹出的所有 Edge 窗口，等待任务结束后重试。勿把 collector.profile_dir 指向个人日常 Edge 的配置目录。程序使用独立的 browser-profile，登录与采集共用它。

**X 改版后一直采集失败**：保留运行日志和 `meta.json`，将报错步骤提供给维护者；分享前去除个人信息。不要反复点击或删除数据。维护者需要更新 Playwright 页面选择器后发布新版，现有历史报告仍可查看。CI 的模拟站点测试只验证采集协议，不能证明最新真实 X 页面兼容。

**无法退出**：任务运行期间请等待任务结束后关闭，避免中断下载或建议生成。若等待异常，请保留运行日志并检查当前采集进程。
