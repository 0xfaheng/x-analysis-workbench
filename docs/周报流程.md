# 每周 X 周报流程（给助手看的执行说明）

工作台目录：`<工作台目录>`（下称 ROOT）。全程只读 X 账号，不发帖、不删帖、不改设置。

## 第 1 步：采集 + 分析

```bash
cd "<工作台目录>" && ./scripts/run_weekly.sh
```

- 采集通过 ego-browser（ego lite 的「您的 Chrome 数据」配置，需已登录 X 账号 @0xfaheng）完成：资格页、Analytics 概览 CSV（全部和仅认证）、90 天帖子 CSV、受众页文本，存到 `data/raw/<日期>/`。
- 退出码 3 表示 **X 未登录**：不要尝试登录，直接通知用户「请在 ego 浏览器里登录 X 后告诉我，我再补跑」，结束本次任务。
- 其他采集失败：先看 `data/raw/<日期>/meta.json` 和报错；同一天可用 `--skip-collect` 只重跑分析。不要换用别的浏览器。
- 分析完成后生成 `reports/<日期>/analysis.json`、`report.md` 草稿和 `report.html`，`data/history.json` 追加本期指标。
- 退出码：3 = X 未登录，4 = 采集失败（含 ego 浏览器连接失败），5 = 找不到装有 markdown 的 Python；遇到这三种情况都直接通知用户。

## 第 2 步：阅读材料

1. `docs/策略基线.md`（规则、诊断基线、策略、阶段目标）。
2. 本期 `reports/<日期>/report.md` 和 `analysis.json`（`week_posts` 有本周每条主帖的全文与指标）。
3. 上一期报告的「下周调整建议」（如有），逐条对照本周数据评估是否执行、效果如何。
4. 如需了解用户最近在做什么项目以便建议选题，可读 `<项目背景文件>` 的「当前焦点」（只取能公开讲的项目经历，不写客户名称、密钥、内部数据）。

## 第 3 步：撰写「下周调整建议」

把 `report.md` 中 `<!-- SUGGESTIONS:START -->` 与 `<!-- SUGGESTIONS:END -->` 之间的占位文字替换为建议正文（保留这两行标记）。要求：

- 用简体中文，先写**一句话结论**：本周离门槛更近还是更远、最关键的一个问题。
- **上周建议执行情况**（第一期省略）：逐条写「已做 / 部分做 / 没做」+ 数据表现。
- **本周做对了什么、做错了什么**：各 1–3 条，必须引用具体帖子（日期 + 曝光数）作为证据。
- **下周 3–5 条调整动作**：每条都可执行、可在下周报告中用数据检验（例如「AI 主帖 ≥ 8 条」「发 1 篇 Article，主题为……」）。不要泛泛而谈。
- **下周选题清单 5–7 条**：基于用户真实项目与本周数据表现最好的方向，写出每条的第一行（钩子句）和要点，标注中文或英文。不要替用户编造经历或数字；需要用户补充的数据写「（待补：……）」。
- **风险处理**：对风险提示中的帖子给出删除、修改或保留的建议和理由。
- 阶段目标是否需要调整：连续两周全部达标或明显不切实际时提出，并说明改 `config.json` 的哪一项（不要自行修改）。
- 只依据数据和规则下结论；分类、风险标记是关键词规则，有误判时直接指出。判断误判前先看 `analysis.json` 里该帖实际的 `category` 和 `risks` 字段，不要只凭正则推测（例如「喊单式表述」规则只对归为 web3 的帖子生效，AI 帖里的「Pro 20x」不会被标记）。

## 第 4 步：生成网页并交付

```bash
python3 scripts/render.py --root "<工作台目录>"
```

- 重新生成 `reports/<日期>/report.html`（带上刚写的建议），并刷新 `index.html`。用户在桌面应用「X分析工作台.app」里看报告，应用会自动显示新一期，无需打开浏览器。
- 用 mirasim 的 deliver_artifact 把 `reports/<日期>/report.html` 发给用户，并用 3–5 行文字概括：门槛进度变化、目标达成数、最关键的下周动作。
- 不要把任何文件写进 `~/Documents/Obsidian/我的坚果云/`（库内只允许 .md，非 md 写入会被守卫移走）。

## 维护

- 分类关键词、风险规则、阶段目标都在 `config.json`。
- X 改版导致采集失败时，修 `scripts/collect.mjs`；资格清单图标判断在 `scripts/analyze.py` 的 `ICON_MET` / `ICON_UNMET`。
