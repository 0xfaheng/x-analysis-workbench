# 每周 X 周报流程

工作台全程只读 X，不发帖、不删帖、不改设置。普通报告与下周建议由本机程序完成，无需AI。

## 第1步：更新数据与建议

桌面点击「更新数据与建议」，或在工作台根目录运行：

```bash
python scripts/run_weekly.py
```

Mac 仍可用 `./scripts/run_weekly.sh`。按本机配置选择 ego、Playwright 或 OpenCLI 后端；OpenCLI 可复用日常Chrome登录态，其他模式的登录方法见README。保持目标账号一致，不复制日常浏览器配置。验证码、人工验证或登录由本人处理。

原始数据保存在 `data/raw/日期/`；程序生成 `reports/日期/analysis.json`、`report.md`、`report.html` 和首页 `index.html`。第8节是下周建议，第9节是有来源及核验日期的官方规则摘要。

失败时查看日志和 `meta.json`。退出码2为配置错误、3为未登录目标账号、4为采集或输入失败、5为缺少markdown、6为浏览器或桥依赖缺失、7为已有任务运行。不要并发补跑。遇到平台明确验证或访问限制时停止并通知本人，不绕过验证。

## 第2步：阅读与复查

阅读本期数据、建议及 `docs/策略基线.md`。程序区分官方条件与运营实验，每条列明数据依据、动作和复查方法。下一期可复查的仅是导出数据里的指标；不能由指标断言行动已执行或证明因果。年龄、本人地区、权属、收款、账号状态等仍需本人核对。

默认分类和阶段目标是AI/web3中文创作者示例，其他用户按自己的方向在 `config.local.json` 调整。官方规则与时效说明见 [程序建议与官方规则](程序建议与官方规则.md)。规则不是实时联网更新，超过30天提示复核。

## 第3步：可选人工或AI深度撰写

程序建议已可直接使用。不需要额外撰写时，完成第1步即可。

如需人工或本人配置的AI进一步分析，先阅读本期 `analysis.json`、报告、个人策略及上期建议。用事实和具体帖子支持结论；不编造经历、客户或数字，不把关键词命中当作X违规认定，不擅自声称符合完整奖励资格。

把 `report.md` 中 `<!-- SUGGESTIONS:START -->` 与 `<!-- SUGGESTIONS:END -->` 之间的内容替换为新建议，保留这两行标记。人工编辑会被保留；未修改的程序建议会自动更新。AI不得代替本人完成原创创作或自动发布。

## 第4步：使用已有数据重新生成

```bash
python scripts/run_weekly.py --skip-collect --date YYYY-MM-DD
```

桌面「重新生成网页」执行同类流程，使用已有CSV重新统计、更新未编辑的程序建议并渲染，不打开浏览器。只修改正文且不希望重新分析时可用 `python scripts/render.py --root .`。用户数据、报告及策略不应提交公开仓库；分享软件使用官方发布包或不含个人数据的源码。
