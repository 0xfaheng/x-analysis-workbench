# 开发与发布

Python 3.10+，Node用于脚本语法和前端测试。源码桌面版还需安装本平台的 `packaging/requirements-*.txt`。个人设置使用 `config.local.json`，不要改公共账号默认值或提交个人数据。

## 测试

```bash
python -m unittest discover -s tests
```

测试使用合成数据。显式设置 `XWB_BROWSER_TESTS=1` 时，会用系统浏览器测试本地模拟站点，不访问真实X。`XWB_BROWSER_CHANNEL` 可指定 `msedge` 或 `chrome`。CI覆盖Windows、macOS和Linux。

已有数据重算：`python scripts/run_weekly.py --skip-collect --date YYYY-MM-DD`。只渲染现有报告：`python scripts/render.py --root .`。运行中的数据更新使用进程锁；退出码与常见问题见各平台安装说明。

## 构建

- Windows：`./packaging/build_windows.ps1`。
- Apple Silicon Mac：`bash packaging/build_macos.sh python3`。

构建流程执行测试、PyInstaller冻结与合成数据冒烟，规则快照随包分发。Windows产出安装包和便携ZIP；Mac产出DMG和ZIP。个人配置、登录态、原始数据、报告和个人策略不随包分发。

`app/`保留可选的Swift原生Mac入口，使用同一份数据和Python脚本，需在Apple Silicon Mac上自行编译：`app/build.sh`。它的默认数据目录与Python安装版不同，可用 `XWB_ROOT` 指向同一目录。

## 发布

版本只在 `scripts/version.py` 维护，对应说明写入 `CHANGELOG.md`。测试后提交并推送代码，再创建与源码版本一致的 `vX.Y.Z` 标签。标签触发Windows和Mac构建，两边成功后统一创建GitHub Release并上传四个附件；手动触发工作流只构建、不发布。

X官方规则摘要位于 `rules/x-official-rules.json`，需核对原始官方页面后再更新版本和核验日期，不能仅通过重跑报告宣称规则已更新。操作方法见 [程序建议与官方规则](程序建议与官方规则.md)。
