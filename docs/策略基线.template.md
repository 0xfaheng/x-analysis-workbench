# X 账号策略基线（个人模板）

> 首次启动会复制本模板为 `docs/策略基线.md`。在生成的个人文件中填写账号与策略，不要提交个人诊断数据。每周写建议前先读个人文件；调整时注明日期。

## 一、X「原创内容奖励」规则要点

本机随软件分发的官方规则摘要、门槛、来源与核验日期保存在 `rules/x-official-rules.json`。周报第9节展示摘要与官方链接，维护方式见 [程序建议与官方规则](程序建议与官方规则.md)。申请前以官方页面和本人 Creator Studio 为准。

个人运营目标与X官方条件分别记录：发帖数量、语言、内容题材等由本人设定，不能当作平台通用要求。不要把Analytics总曝光或认证用户总曝光等同于奖励计划合格曝光；不要推断本人年龄、地区、身份或完整收款资格。
