# Mac 安装与使用

仅支持 Apple Silicon（M 系列芯片，arm64）和 macOS 13.5 及更新版本，不支持 Intel Mac。请准备可访问 X 的网络，以及 Google Chrome 或 Microsoft Edge。已有 ego lite / ego-browser 时，更新数据会自动优先使用 ego。

## 1. 下载与安装

1. 打开 [Releases 最新版](https://github.com/0xfaheng/x-analysis-workbench/releases/latest)，下载 `XWorkbench-版本号-macOS-arm64.dmg`。
2. 双击 DMG，将 `XWorkbench.app` 拖到旁边的「应用程序」快捷方式。不要在 DMG 内长期运行。也可下载同名 ZIP，解压后把应用拖入「应用程序」。
3. 从「应用程序」打开「XWorkbench」（显示名「X分析工作台」）。首次可能需要按下面的方法允许打开。

安装包只做 ad-hoc 签名，未经 Apple 公证。macOS 14 及更早版本通常可在访达中右键应用 →「打开」→ 再次确认「打开」。macOS 15 及更新版本通常需要先尝试打开一次，再到「系统设置 → 隐私与安全性」，在安全性区域点击「仍要打开」，按提示验证。不同系统小版本的文案可能略有差别；只对确认来源的下载文件执行。

若提示「已损坏」，确认下载来自本仓库后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/XWorkbench.app
```

然后重新打开。首次访问「文稿」文件夹时系统询问授权属正常现象，请允许工作台保存数据；若误拒绝，可在「系统设置 → 隐私与安全性 → 文件与文件夹」中检查工作台权限。

## 2. 首次使用

1. 在设置卡片填写自己的 X 用户名，可带或不带 `@`，限 1–15 位字母、数字或下划线。点「保存用户名」，设置写入本机 `config.local.json`，保留其中其他配置。
2. 点「登录 X」，在自动选择的 Chrome 或 Edge 专用窗口中手动登录目标账号。密码、验证码及双重验证均由本人处理，工作台不代填。识别账号后关闭窗口；未登录正确账号时最多等待 15 分钟。
3. 点「仅更新数据」，完成后左侧选择报告、右侧查看指标及正文。日常双击应用即可查看已有报告。
4. 修改账号使用「更多 → 修改 X 用户名」，然后重新登录。已有历史数据保留在原目录；需要隔离不同账号时用不同的 `XWB_ROOT`。

Playwright 默认按 Chrome → Edge 尝试。未安装任何浏览器时会提示「请安装 Google Chrome 或 Microsoft Edge」，退出码 6。显式设置 `collector.browser_channel` 时按该配置执行，不自动回退。工作台不捆绑或自动下载安装浏览器。

**已安装 ego lite 的用户**：macOS 的 `collector.backend=auto` 更新数据会优先使用 ego-browser，沿用 ego 的会话；只有找不到 ego 时才选 Playwright。「登录 X」始终是 Playwright 专用窗口，不能登录 ego 会话。要使用 ego，请在 ego lite 中手动登录同一账号并保持运行；要始终使用专用 Chrome / Edge，可在 `config.local.json` 中设置 `"collector": {"backend": "playwright"}`。

## 3. 数据、建议与升级

默认数据目录是用户主目录下 **Documents/X分析工作台**，访达通常显示为「文稿/X分析工作台」。使用「更多 → 打开工作台文件夹」可找到实际位置。

| 内容 | 位置 |
|---|---|
| 本机用户名与覆盖配置 | `config.local.json` |
| 公共规则副本 | `config.json` |
| 原始数据 / 历史指标 | `data/` |
| 报告 / 手写建议 | `reports/` |
| Playwright 专用登录态 | `browser-profile/` |
| 个人策略 | `docs/策略基线.md`，由模板首次生成，之后不覆盖 |

「更多 → 查看策略基线」打开个人策略。「下周调整建议」可由已配置的本机 mirasim 任务生成；也可按 [周报流程](周报流程.md) 修改本期 `report.md`，保留建议区块标记，再点「重新生成网页」。每 20 秒刷新保留当前报告选择。任务中请等待完成再退出。

升级前先备份整个数据目录，关闭旧版，用新版替换「应用程序」中的 `XWorkbench.app`。卸载只需移走应用，数据目录保留。`XWB_ROOT` 可指定其他目录；此 Python 安装版与可选 Swift 原生版的默认 root 不同，旧用户应继续沿用原入口或显式指定。

## 4. 常见问题

- **退出码 2**：先设置用户名，检查 JSON 标点与 collector 配置。
- **退出码 3**：未识别目标账号；确认登录的会话与所用后端一致，再重试。
- **退出码 4**：查看运行日志及 `data/raw/日期/meta.json` 的 step/error；确认网络可用，关闭占用 CSV 的软件。X 改版可能需要更新采集器。
- **退出码 5 / 6**：安装包用户重新下载最新版本；源码用户安装依赖，6 还需检查 Chrome / Edge 是否已安装。
- **退出码 7 / 配置目录被占用**：等待已有任务结束，关闭工作台先前弹出的专用浏览器后重试。进程失效或超过 2 小时会自动回收运行锁。
- **没有建议**：数据更新本身不写建议，按上文配置助手或自行填写。
- **仍无法打开 / 页面空白**：保留日志、系统版本与芯片信息，去除个人数据后提供给维护者。首次启动、文稿授权和 WebKit 界面仍需真实环境核对。
